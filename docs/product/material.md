# Material: 松赞用户关系助手 · 销售培训

## 1. Overview
- 用户关系助手是松赞一线销售管理客户、记录跟进、处理待办的核心工作台
- 面向全体一线销售和销售负责人，版本 v1.0，2026年5月上线
- 核心价值：让销售知道每天该联系谁、如何记录跟进、谁是重点维护客户

## 2. Background
- 松赞销售团队日常面临客户管理分散、跟进记录不规范的问题
- 工具整合了会员中台数据与销售日常工作流，打通 CDP 数据同步
- 支持切换销售员视角，适合销售负责人统筹管理团队

## 3. Key Info
- 三大核心模块：我的待办（左栏）、维护记录（右栏）、会员查询及维护
- 待办系统：分已过期/今日到期/即将到期/已完成 4 个 Tab，颜色区分优先级
- 客户分层：当年复购非核心（优先维护）、当年首购非核心（建议维护）、名下会员数、本月维护次数
- 维护记录字段：维护日期、维护行为（4类）、客户反馈、出行需求、提醒事项

## 4. Evidence
- 重点操作场景1：每日查看过期和今日到期待办
- 重点操作场景2：通话后记录维护记录
- 重点操作场景3：主动开发首购非核心潜力客户
- 重点操作场景4：通过会员查询认领新客户

## 5. Analysis
- 系统不会主动推送微信通知，需销售主动登录查看待办
- 维护记录不可删除，只能编辑，所有操作留有日志
- 已有归属销售的会员不能被二次认领
- 会员姓名和所在地修改实时同步 CDP，其他字段需通过其他入口修改

## 6. Outlook
- 培训目标：5分钟内让销售理解工具价值，掌握3个核心操作路径
- 培训对象：全体一线销售、销售负责人
