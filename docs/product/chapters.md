## Page 8: 新增维护记录
- **Page Type**: Content
- **Page Title**: 如何新增维护记录
- **Selected Template**: (TBD)
- **Content Structure**:
  - 操作入口：右栏右上角「+ 新增维护记录」按钮，或通过会员查询进入
  - 7步操作流程：
    1. 点击「+ 新增维护记录」
    2. 选择要记录的会员
    3. 填写维护日期
    4. 选择维护行为（线下拜访 / 电话回访 / 活动邀约 / 微信沟通）
    5. 填写客户反馈（**尽量详细**，是日后回顾的唯一依据）
    6. 如有出行需求，填写出行需求信息（时节、组合、预算、天数、偏好）
    7. 如需提醒，填写提醒事项和提醒时间（自动生成待办）→ 保存
  - 注意：维护行为必填；出行需求建议尽量填完整，是你自己的销售素材
- **Content Density**: Heavy
- **Narrative Role**: 手把手讲解核心操作，7步流程确保学员上手无障碍
- **Image Requirements**: 无
- **Page Weight**: Core page
